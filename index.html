Sistema de Respaldo — FiscalSync

Backup & Restore

Información del Respaldo

Genera una copia de seguridad completa de todos los datos del sistema: empresas, usuarios y todos los registros fiscales de todos los meses. El archivo JSON descargado puede usarse para restaurar el sistema en cualquier momento.

El backup incluye:

Todas las empresas · Todos los usuarios · Proveedores, Clientes y Empleados de cada empresa · Todos los registros mensuales (Débito, CF, Compras, IVA Percibido, IVA Retenido, Anticipo, Excluidos, F14, Quincena Veinticinco) de todos los períodos almacenados, incluyendo el estado de Consulta DTE de cada documento · Módulo de Correos (documentos generados, historial de envíos y plantillas) · Estados de Modo Revisión de cada libro.

Restaurar desde Backup

Carga un archivo de backup previamente generado por FiscalSync. El sistema validará su estructura antes de procesarlo. Advertencia: esta acción reemplazará todos los datos actuales.
